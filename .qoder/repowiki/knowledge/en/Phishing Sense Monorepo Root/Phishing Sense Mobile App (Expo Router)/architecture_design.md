Built on Expo Router with file-based routes split into two top-level groups: `app/(auth)` for the unauthenticated flow (splash, login, signup, forgot-password, onboarding) and `app/(app)` for the authenticated shell. The root `app/_layout.tsx` wraps the entire app in a provider stack — `GestureHandlerRootView` → `SafeAreaProvider` → `ThemeProvider` → `LanguageProvider` → `AuthProvider` → `AppProvider` — then renders an `expo-router` `Stack` containing the three route groups plus the index redirect. `app/index.tsx` is the entry gate that redirects to `(app)/home` when authenticated or `(auth)/splash` otherwise. The authenticated shell (`(app)/_layout.tsx`) renders a `Tabs` navigator with screens home, scan, sense-ai, profile, plus hidden panic and settings screens. Cross-cutting concerns live under `src/`: `store/AppContext.tsx` provides both `AuthProvider` (mock login/signup/logout/reset) and `AppProvider` (scan history, stats, AI chat messages, text size, notifications); `i18n/` initializes i18next with English and Urdu resources, persists language via AsyncStorage, and drives RTL layout switching; `theme/` exposes light/dark themes built from shared design tokens in `tokens.ts`; `components/ui/` holds presentational primitives (Button, Card, Input, Badge, Header, BrandLogo, LanguageToggle, SenseOrb). Dependency direction is one-way: pages consume contexts via hooks (`useAuth`, `useApp`, `useTheme`, `useLanguage`) and never mutate them directly.
