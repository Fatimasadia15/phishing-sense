This root is a flat monorepo with two sibling child modules — `mobile_app` (Expo Router-based React Native client) and `server` (Express API providing `/api/analyze`). The root `package.json` belongs to the mobile app entry point (`index.ts` → `App.tsx` via `registerRootComponent`) and declares Expo/React Native dependencies; the server lives in its own directory with independent scripts. Cross-child communication is by HTTP: the mobile app calls the backend's `/api/analyze` endpoint to obtain phishing risk scores, while no shared code or build-time wiring exists at this level beyond workspace layout.
