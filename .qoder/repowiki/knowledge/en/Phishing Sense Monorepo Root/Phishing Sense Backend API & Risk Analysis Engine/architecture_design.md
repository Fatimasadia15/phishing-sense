Single-process Node.js application built on Express. `src/server.js` is the entry point: it loads `.env`, mounts security middleware (`helmet`, `cors` with Expo dev origins), global rate limiting (`express-rate-limit`), body parsers, a `/api/health` probe, and the main `POST /api/analyze` route. The route composes three pipeline stages in `src/engine/`: first `rules.analyzeWithRules()` runs a deterministic heuristic scanner (URL shortener/TLD/lookalike checks, urgency/credential/scam/impersonation regexes, Pakistani carrier detection) producing a `ruleScore`, `verdict`, `indicators`, and a redacted input; then `llm.callLlm()` optionally queries an OpenAI-compatible chat endpoint using the redacted text (fails gracefully so the service degrades to rules-only); finally `combine.combineResults()` merges both signals into a unified response. Input validation is isolated in `src/middleware/validate.js` as an Express middleware enforcing `input` (string, non-empty, ≤ MAX_INPUT_LENGTH) and `input_type` ∈ {text, link, message}. Dependency direction is strictly one-way: routes → engine modules; engine modules do not import routes or middleware. Tests live under `__tests__/analyze.test.js` and are run via `node --test`.
